# 0.1.2 发布前安全审查

日期：2026-10-15。范围：本仓库公开文件清单内的源码、构建脚本、文档、示例截图，以及 0.1.2 发布附件。本记录说明实际检查范围，不构成安全认证或零风险保证。

## 本次改动与检查

- 主题色只接受预设标识，拒绝未知值、非字符串及注入内容；旧版没有该字段的备份保持兼容。
- 主题通过现有本地存储和备份机制保存，存储失败时保持原配色，不新增网络接口或权限。
- Android 仅将固定配色映射到系统栏背景，不接受任意颜色代码或文件路径。
- 构建可通过环境变量指定已有签名目录；签名私钥和密码始终位于公开文件清单之外。
- 保留 0.1.1 的导入校验、输出转义和内置脚本哈希限制。历史说明见 [0.1.1 审查](SECURITY-REVIEW.md)。

## 验证边界

尚未在真实安卓设备或安卓模拟器上完成安装和交互验收，接口模拟不能替代原生执行。未进行第三方渗透测试或 Android System WebView 安全审计。静态扫描无法识别所有敏感信息格式或未知漏洞。

应用记录及 JSON 备份没有额外加密。公开 APK 包含签名验证所需的公开证书，不包含发布私钥。设备被入侵、用户主动分享资料或选择第三方云盘保存备份的行为，不在这些检查的可控范围内。
