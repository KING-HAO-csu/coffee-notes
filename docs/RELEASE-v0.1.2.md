# 0.1.2 · 个性化设置

本地开发版，尚未发布 GitHub Release。

## 新增

- 「我的 → 外观与主题色」提供森林绿、咖啡棕、奶油米、雾霾蓝、莓果紫五种配色。
- 主题色可分别搭配浅色与深色模式，选择后立即保存，重开应用与备份恢复后保留。
- 安卓系统栏随配色与明暗模式更新。

## 改善

- 豆子和咖啡店页面右上角的「新豆子」「新店铺」采用更小的自适应字号，文字保持单行，点击区域至少 44 像素高。
- 对比页的参数差异随当前主题色突出显示。

## 兼容与验证

- 旧版数据没有主题色字段时默认使用森林绿，保留原有明暗模式和记录。
- 主题保存失败时显示错误并保持原配色，可在恢复存储后重试。
- 完成核心数据、浏览器交互与安卓接口模拟检查，覆盖主题保存、旧备份、窄屏和横屏布局。
- APK 使用原有发布签名，版本号为 0.1.2（versionCode 3）。尚未完成安卓真机安装和交互验收。

更新前可在「我的」导出备份，再直接覆盖安装。网页预览与 APK 各自保存数据，迁移时使用备份导入。
