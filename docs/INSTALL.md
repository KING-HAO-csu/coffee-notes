# 咖啡手记安装说明

适用于 Android 8.0 及以上手机。安装文件为 `coffee-notes-0.1.1.apk`。

## 安装到手机

1. 将 APK 文件传到手机，例如通过 USB、聊天文件传输或自己的网盘。
2. 在手机的文件管理器中找到 APK，点开并选择安装。
3. 如果系统询问是否允许来自当前文件管理器或浏览器的应用，请允许本次安装来源，再返回继续安装。不同手机提示名称可能稍有不同。
4. 安装后打开「咖啡手记」。首次启动包含有标记的示例记录，方便熟悉功能。

## 数据保存与迁移

日常记录可离线使用，数据保存在手机内的应用中。网页预览与 APK 使用各自的数据存储，安装 APK 后不会自动带入浏览器里的记录。

要迁移已有数据，在网页预览的「我的」中导出备份，将备份文件传到手机，再到 APK 的「我的」中导入备份。导入前请阅读应用显示的确认提示；如果手机内已有需要保留的记录，请先导出一份手机上的备份。

建议定期把备份保存到手机以外的位置。卸载应用或清除应用数据会移除本机记录，操作前请先导出备份。后续更新时，使用相同签名的新版 APK 直接覆盖安装即可保留数据。

## 当前版本验证范围

APK 的编译、签名、安装包结构和对齐检查结果见同目录的「构建验证.txt」。网页功能已进行浏览器自动化检查，Android 与网页之间的备份、返回和草稿接口已进行模拟检查。

当前尚未在实际 Android 手机上完成安装和交互验收。首次安装后，建议先新建一条试用记录，关闭再打开应用确认记录仍在，再试一次照片选择与备份导出。具体表现取决于手机系统及 Android System WebView 版本。
