# 0.1.1 发布前安全审查

日期：2026-10-14。范围：本仓库明确列出的源文件、构建脚本、文档、示例截图，以及对应的发布附件。此记录是有边界的检查结果，不是安全认证或零风险保证。

## 修复内容

- 备份中店铺评分、复盘日期和部分嵌套字段此前检查不足，可能进入 HTML 渲染。0.1.1 加入类型、范围、编号和嵌套对象检查；评分显示转换为有限整数，日期和阶段水量输出转义。
- 构建时计算两个内置脚本的 SHA-256，生成脚本白名单策略，禁止任意内联事件和未授权脚本。页面不依赖外部资源。
- 源码归档改为精确文件名单；不递归收集浏览器资料或临时目录。仓库忽略签名密钥、密码、构建工具、用户备份和测试浏览器资料。

## 尚未覆盖

- 未在真实安卓手机或安卓模拟器上完成验收；浏览器原生接口模拟不等于真机测试。
- 静态扫描不能识别所有个人信息或所有漏洞；虚构示例性质同时依靠人工检查。
- 应用数据和 JSON 备份没有额外加密；设备被入侵、用户主动分享或第三方云盘行为不在应用可控范围内。
- 未进行第三方渗透测试或 Android System WebView 本身的安全审计。浏览器测试环境对部分策略指令出现兼容性警告，脚本拦截有实测证据；Android APK 中的策略和系统行为仍待真机验证。

发布私钥保留在开发者本地，不随仓库、源码归档或 APK 公开。APK 内的签名证书是公开验证材料，不含签名私钥。
