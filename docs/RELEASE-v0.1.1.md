### Added

- 首次公开咖啡手记：冲煮后快速补记、豆子档案、分类风味、同豆双列对比与咖啡店品饮记录。
- 支持三种研磨计量、时间滚轮、可选分段累计注水、配方复用与待补记草稿。
- 提供 Android 8.0+ 离线安装包、独立网页预览、浅深色模式和 JSON 备份迁移。
- 公开 MIT 许可源码、构建说明、隐私说明与发布前审查记录。

### Fixed

- 修正备份中评分、日期和嵌套字段的检查，非法资料不会覆盖已有记录。

### Security

- 修复恶意备份可能触发的页面注入，并增加只允许运行内置脚本的限制。
- 源码打包采用明确文件清单，排除签名材料、浏览器资料、备份和临时工具。

安装文件为 `coffee-notes-0.1.1.apk`，网页文件为 `coffee-notes-preview.html`。校验值见 `SHA256SUMS.txt`。
